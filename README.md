TRAZA//CO2 - PWA Financial Suite & Cuenta de Resultados

Aplicación web progresiva (PWA) profesional de control financiero, cuenta de resultados (P&G) y Business Intelligence para TRAZA//CO2 (WMS - Sistemas de Trazabilidad Carbono Logística 5.0).

Características Principales

Dashboard Financiero Dinámico y KPIs: Burn Rate, Margen Bruto, EBITDA y Punto de Equilibrio en tiempo real.

Conciliación Bancaria Open Banking: Emparejamiento automatizado de cobros y pagos.

OCR Inteligente de Facturas: Extracción de importes mediante subida o cámara.

Contabilidad Analítica: Asignación de costes por proyectos y líneas WMS.

Devengo vs. Criterio de Caja: Alternancia de vistas contables instantáneas.

What-if Forecast: Simulador interactivo de escenarios de mercado y desviaciones Budget vs. Actual.

Soporte PWA Offline: Service Worker integrado para funcionamiento sin conexión.

Estructura del Repositorio

index.html: Aplicación web autocontenida y optimizada.

manifest.json: Manifiesto de la Progressive Web App (PWA).

sw.js: Service Worker para caché y soporte offline.
